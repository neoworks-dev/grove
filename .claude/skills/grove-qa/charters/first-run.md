# First run: what someone sees when they open Grove having never used it

Start from a fresh profile (`qa start --fresh`). Go through what the app puts in
front of you in the order it puts it there — the setup wizard, the empty states,
the first pane you land in. Try to do the obvious first things without reading
any documentation, and note every point where you had to guess.

Watch for: empty states that say nothing about what to do next, a wizard step
that cannot be skipped or cannot be undone, controls whose labels only make sense
if you already know the app, anything that looks broken but is merely empty.
