# The GitHub surfaces: issues, pull requests, the dashboard

The demo repo's remote is the sandbox `neoworks-dev/grove-qa-sandbox`, and you
may write to it freely. Browse issues and pull requests, open one, read the
timeline, comment, filter and search. Create an issue from inside Grove. Push a
branch and open a pull request from inside Grove, then check out that pull
request and read its diff.

Watch for: a list that never loads or never refreshes, a view that throws the
code layout away when it opens, markdown that renders wrongly, a link that
navigates the whole window, paths in a body that will not open, a checked-out
pull request that does not catch up with the pull request.
