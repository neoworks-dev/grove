# The editor: buffers, tabs, vim, saving

Open files from the explorer and the file finder. Edit them — insert, delete,
undo, redo, search, replace, visual selections, multiple buffers at once. Save,
and check the file on disk. Open the same file twice. Open something large, and
something with no trailing newline.

Watch for: keys that arrive before nvim owns the buffer, a tab whose unsaved dot
disagrees with the buffer, the status bar going stale, the minimap drifting out
of step, a file that opens in the wrong pane.
