# Agents: the composer, the transcript, the review flow

Start one session and keep the prompts tiny — this spends real tokens. Ask for a
one-line change to a file in the demo repo. Watch the transcript as it runs: the
status, the stop control, tool calls folding in and out. Let it edit something and
take the review to the end — accept a hunk, reject a hunk, leave a comment.

Watch for: a session that reads idle while it is running, a message split across
two bubbles, a Stop that does not, a review diff that renders empty or vanishes
when the active tab changes, a verdict that is not what lands on disk.
